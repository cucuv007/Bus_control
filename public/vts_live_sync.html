🚌 VTS Live Sync - SA65 Gerçek Zamanlı Takip

Kentkart VTS'den canlı veri çekme ve senkronizasyon sistemi

📋 Kullanım Talimatları

  1. Yeni sekmede VTS'ye giriş yapın
  2. VTS sekmesinde F12 tuşuna basın (Console açılsın)
  3. Aşağıdaki kodu Console'a yapıştırın ve Enter'a basın
  4. Bu sayfaya geri dönün - her 5 saniyede otomatik güncellenecek
// SA65 verilerini her 5 saniyede LocalStorage'a kaydet setInterval(() => { fetch('https://vts.kentkart.com.tr/api/026/v1/latestdevicedata/get?fields=bus_id,car_no,display_route_code,lat,lon,speed,status,path_name,comp_name,personel_name,personel_last_name,bearing,date_time,odometer&sort=bus_id|asc&dc=' + Date.now()) .then(r => r.json()) .then(d => { // d.data.data nested yapısı const allVehicles = d.data?.data || []; const sa65 = allVehicles.filter(v => v.display_route_code?.includes('SA65') || v.display_route_code?.includes('SA-65') || v.path_name?.includes('SA65') || v.path_name?.includes('SA-65') ); localStorage.setItem('vts_sa65_live', JSON.stringify({ timestamp: new Date().toISOString(), vehicles: sa65, count: sa65.length, total: allVehicles.length })); console.log('✅ SA65 güncellendi:', sa65.length, '/', allVehicles.length, 'araç'); console.table(sa65.map(v => ({ Plaka: v.car_no, Lat: v.lat, Lon: v.lon, Hız: v.speed, Durum: v.status === 1 ? '🟢 Aktif' : '🔴 Pasif' }))); }) .catch(e => console.error('❌ VTS sync error:', e)); }, 5000); // İlk çalıştırmayı hemen yap fetch('https://vts.kentkart.com.tr/api/026/v1/latestdevicedata/get?fields=bus_id,car_no,display_route_code,lat,lon,speed,status,path_name,comp_name,personel_name,personel_last_name,bearing,date_time,odometer&sort=bus_id|asc&dc=' + Date.now()) .then(r => r.json()) .then(d => { const allVehicles = d.data?.data || []; const sa65 = allVehicles.filter(v => v.display_route_code?.includes('SA65') || v.path_name?.includes('SA65')); localStorage.setItem('vts_sa65_live', JSON.stringify({timestamp: new Date().toISOString(), vehicles: sa65, count: sa65.length, total: allVehicles.length})); console.log('🟢 VTS Live Sync başlatıldı!', sa65.length, 'SA65 araç bulundu.'); });
